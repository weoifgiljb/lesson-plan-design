# 组件库与页面验收清单

> 与 `ui-style-spec.md` 配套。每个页面/组件 PR 按本清单逐项打勾；结论写入 `.qa/reviews/frontend-<分支>-<日期>.md`。

## 1. 组件矩阵（Element Plus）

| 组件 | 使用场景 | 必测状态 | 视觉检查 | 交互/无障碍 |
|---|---|---|---|---|
| `ElButton` | 主/次/危险动作 | 默认、hover、active、disabled、loading | 高度 32/36、主按钮每屏 ≤1、图标与文字间距 6 | 键盘触发、loading 时防重复提交 |
| `ElInput` / `ElSelect` / `ElDatePicker` | 筛选、表单 | 空、有值、清除、disabled、校验错误 | 高度 32、placeholder 对比度、错误文案在下方 | label 关联、错误 `aria-describedby` |
| `ElForm` | 登录、建课、建号 | 必填、格式错误、提交中、成功 | label 顶部、间距 16、错误不抖动 | 提交中禁用、首个错误聚焦 |
| `ElTable` | 教案/审查/任务/审计 | 空、加载、错误、超长文本、排序、分页 | 表头 44、行高 44、斑马纹可选、数字右对齐 | 键盘滚动、空态含动作、分页可达 |
| `DataTable` 封装 | 所有列表页统一入口 | 空、加载、错误、分页、选择、行点击 | 外层 1px 描边 + 10 圆角；表头透明、底部细线；工具栏与表格一体 | 不直接写 `el-table`；错误态可重试、空态给动作 |
| `ElPagination` | 列表页 | 首页/末页/跳页 | 右对齐、总数文案 | 键盘可达 |
| `ElDialog` / `ElDrawer` | 详情、确认、上传 | 打开、关闭、Esc、遮罩、危险确认 | 标题 16、圆角 10、最大宽 720/960 | 焦点陷阱、关闭后焦点归位 |
| `ElTag` / `ElBadge` | 审查/导出/证据状态 | 六种审查状态、导出成功/失败 | 颜色+文字、对比度 | 不只靠颜色；`aria-label` |
| `ElTabs` | 详情页（内容/版本/审查） | 默认、禁用、切换 | 下划线 2px、间距 24 | 键盘左右切换 |
| `ElUpload` | 契约包、样例 | 选择、上传中、成功、失败、类型错误 | 拖拽区 1px 虚线、文件列表 | 键盘选择、错误可读 |
| `ElMessage` / `ElNotification` | 操作反馈 | 成功、失败、超时 | 不遮挡主操作、失败含 traceId | 可关闭、屏幕阅读器可读 |
| `ElEmpty` / `ElResult` | 空态、403/404/500 | 空、无权限、错误 | 说明 + 一个动作 | 标题层级正确 |

## 2. 业务展示组件

### 证据链面板

- 五项固定顺序：哈希匹配、轮次连续、放行完整、审校方式合规、状态一致。
- 每项：图标 + 文字结论 + 失败原因；不能只显示红点。
- 缺项可展开到 `reason`；五项全过时显示“证据链完整”。

### 版本差异

- 两列：字段路径 / 前值 → 后值；长文本折叠，保留换行。
- 空差异显示“两个版本内容一致”；单版本/同版本错误要有文案，不是空白。

### 统计指标卡

- 每卡：名称、数值、分子/分母、筛选条件、下钻链接。
- 分母为 0 / 未接入显示“— + 未接入”，不显示 0% 或粗体“暂无数据”；样本 <5 显示“样本不足”，不显示明细。
- 9 项指标不可只显示其中几项；不可用的指标显示“未接入”并说明原因。

### 导出队列

- 逐项状态：排队/成功/失败；失败给 code + message + 重试。
- 成功给文件名、SHA-256 前 12 位、下载按钮。
- 批量部分失败时，成功的仍可下载。

### 任务行

- 逾期：文字“已逾期”+ 截止日期；排序：有截止在前、升序，无截止最后。
- 班级为空显示“未指定”，不显示空单元格。

### 样例行

- `complete=false` 显示“不完整”标签与原因（文件缺失/哈希不符）。
- 管理员上传失败展示 422 issues 列表。

## 5. 无障碍

- [ ] 文字对比度 ≥4.5:1（用 axe 或对比度工具抽查主色/次文字/状态标签）。
- [ ] 键盘可完成主流程：登录→筛选→打开详情→关闭弹窗。
- [ ] 焦点环可见，Tab 不跳入隐藏元素。
- [ ] 图标按钮有 `aria-label`；图片有 `alt` 或 `aria-hidden`。
- [ ] 表单错误与字段关联；错误摘要可聚焦。
- [ ] `prefers-reduced-motion` 下无自动动画。

## 7. 判定

- **通过**：第 1–5 节全部勾选，截图齐全，无视觉/无障碍 blocker。
- **有条件通过**：仅文案、间距、hover 等 minor；列整改项与复查方式。
- **拒绝**：令牌失控、关键状态缺失、四态缺失、响应式断裂、对比度或键盘 blocker。

复查时只检查整改项 + 受影响组件，不重复全量走查。
