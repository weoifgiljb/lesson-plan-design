## 1. Element Plus 组件

| 组件 | 使用场景 | 必测状态 | 视觉检查 | 交互/无障碍 |
|---|---|---|---|---|
| `ElButton` | 主/次/轻色调/危险 | 默认、hover、active、disabled、loading | 32/36 高；主按钮每屏 ≤1；成功/警告/危险优先 `plain` | 键盘触发；loading 防重复提交 |
| `ElInput` / `ElSelect` | 筛选、表单 | 空、有值、清除、disabled、校验错误 | 34 高、6 圆角、标签 12/600 | label 关联；错误在字段下方 |

| `ElTable` | 教案/审查/任务/审计 | 空、加载、错误、超长、分页 | 表头 40、行高 44、透明表头、数字右对齐 | 空态给动作；分页可达 |
| `DataTable` 封装 | 所有列表页统一入口 | 空、加载、错误、分页、行点击 | 1px 描边 + 10 圆角；工具栏与表格一体 | 不直接写 `el-table`；错误可重试 |
| `ElPagination` | 列表页 | 首页/末页/跳页 | 右对齐、12px、总数文案 | 键盘可达 |
| `ElDialog` / `ElDrawer` | 详情、确认、上传、命令面板 | 打开、关闭、Esc、遮罩、危险确认 | 标题 16、圆角 14、最大宽 720/960 | 焦点陷阱；关闭后焦点归位 |
| `StatusTag`（自绘） | 六种审查状态、导出 | 全部状态 | 点 + 文字 + 软底 + 1px 边；不只靠颜色 | 有文字；可加 title |
| `ElUpload` | 契约包、样例 | 选择、上传中、成功、失败、类型错误 | 虚线拖拽区、6 圆角 | 键盘选择；错误可读 |
| `ElMessage` | 操作反馈 | 成功、失败、超时 | 左侧 3px 语义条；不遮挡主操作 | 可关闭；失败含 traceId 时展示 |

## 2. 业务展示组件

### 结构剖面 `StructurePanel`

- 3D 与 2D 两个视图；3D 不可用时自动 2D，不弹错误打断。
- 图例三项固定：三维目标 / 八步流程 / 证据链；显示证据通过数与 45 分钟合计。
- 悬停/点按流程柱更新说明；说明格式为“序号、标题 · 分钟 · 证据”。
- `<details>` 结构清单包含全部八步、分钟、证据与缺项原因。
- 无 WebGL、窄屏、chunk 失败、上下文丢失时，信息不丢失。

### 指标账本 `MetricLedger`

- 每项：名称、数值、单位、分子/分母、口径提示。
- 不可用显示“— + 未接入 + 等待数据源接入”，不显示 0%。
- 单份耗时显示秒与导出次数，不显示占比条。

### 证据链 `EvidenceChain`

- 五项固定顺序；通过/缺项都有文字；缺项原因常显。
- 头部给出 `已通过/总数` 与“还缺 N 项”的结论。

### 版本差异 `DiffViewer`

- 字段路径 / 前值 / 后值；前值 `<del>`、后值 `<ins>`；长文本 3 行截断并保留 title。
- 空差异显示“两个版本内容一致”。

### 命令面板 `CommandPalette`（仅 DEV）

- `Ctrl/Cmd+K` 打开；上下键/Enter/Esc；`aria-activedescendant`；关闭后焦点归位。
- 只搜索页面与操作，不假装搜索业务数据；生产隐藏入口。

## 4. 3D 专项检查

- [ ] 1440 下 3D 首帧完成后可拖拽旋转、悬停更新说明、自动旋转开关、重置视角。
- [ ] 390 下自动使用 2D；无横向溢出；图例与清单仍可读。
- [ ] `?diagram=2d` 强制 2D，且不加载 three chunk。
- [ ] 无 WebGL / chunk 失败 / `webglcontextlost` 自动降级，页面不白屏。
- [ ] `prefers-reduced-motion` 下不自动旋转、无入场动画；拖拽仍可用。
- [ ] 离开视口/切后台暂停渲染；卸载后无残留 `requestAnimationFrame`。
- [ ] 3D canvas 不承载唯一信息；结构清单键盘/读屏可得。
- [ ] 生产 `dist` 不含 fixture 数据（教师名/队列），`/styleguide` 不注册；真实 `/dashboard` 含懒加载 three chunk（首屏不阻塞）。

## 8. 判定

- **通过**：第 1–6 节全部勾选，截图齐全，无视觉/无障碍 blocker；用户回复“通过”后冻结 v1.1。
- **有条件通过**：仅文案、间距、hover 等 minor；列整改项与复查方式。
- **拒绝**：令牌失控、关键状态缺失、四态缺失、响应式断裂、对比度或键盘 blocker。
