# 平台端 UI 风格说明（v1.1 已冻结）

> 状态：**已冻结 v1.1（2026-10-29）**。用户在 2026-10-29 回复“没问题了”，第 11 节记录签字。
>
> 本轮范围：设计令牌、工作台外壳、登录、设计验收页与概览；FE-01 起真实 `/dashboard` 复用该套样式并接后端，固定演示数据只保留在 `/styleguide`，真实系统不展示 fixture。

## 1. 产品与受众

- 教师：建课、送审、看审查结果、导出。
- 教研组长：看本组教案与证据链，做放行决定。
- 管理员：用户、样例、引擎版本与审计。
- 核心任务：**收（契约包入库）、看（教案库/版本）、审（证据链）、导（DOCX）、统（指标）**。
- 信息密度、状态可读、证据可追溯优先于装饰；不是营销页，也不是低密度后台。

## 2. 设计方向：教案校样台

把界面当作一张**校样台**：规则线、页边、批注、版本号与审查印记，而不是“卡片 + 渐变 + 大圆角”的通用后台。

三条原则：

1. **结构即视觉**：用对齐、分组、规则线和表格密度表达层级；卡片只给数据岛。
2. **状态必须有文字**：审查、导出、逾期、证据缺项都给出文字结论；颜色只做辅助。
3. **一屏一个重音**：结构剖面是唯一高投入视觉；其余区域保持安静、低对比、可长时间阅读。

### 参考与取舍

| 参考 | 借用 | 不照搬 |
|---|---|---|
| Linear | 命令优先、紧凑但不拥挤、键盘可达 | 全暗色、紫色光晕 |
| Stripe Dashboard | 指标排版、表格数字、克制的分隔线 | 营销式大数字堆叠 |
| Figma | 工具归工具、内容归内容的“工作台感” | 深色侧栏本身 |
| 瑞士国际主义排版 | 网格、规则线、对齐、层级 | 无圆角、报纸栏密度 |
| 校标教案表（`docs/testing/reference/manual-v2/` 与 `.qa/reference/manual-v2/pages/page-0001.png`） | 教学环节/主要内容/教师/学生四栏的结构感 | 把网页做成 Excel |

避免的默认套路：奶油底 + 高对比衬线 + 陶土色；近黑底 + 荧光绿；每个区块同款圆角卡片 + 同款阴影；全大写小标签；给每个链接加“→”；没有真实顺序的 01/02/03 编号。

## 3. 设计令牌

单一浅色主题 **B「松绿 · 砂岩」**；A「墨蓝」退役，移除 A/B 切换与 `localStorage 'lpp-theme'`。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--lpp-canvas` | `#EDEFEA` | 画布/桌面 |
| `--lpp-layer` | `#F6F7F2` | 侧栏、工具层、表头工具条 |
| `--lpp-surface` | `#FFFFFF` | 数据岛、表格、弹窗 |
| `--lpp-text` | `#17231E` | 主文字 |
| `--lpp-text-muted` | `#5B6A62` | 次文字 |
| `--lpp-border` / `-strong` | `#DDE3D9` / `#C3CEC2` | 规则线 / 表头与输入边 |
| `--lpp-primary` / `-hover` / `-soft` | `#245A4C` / `#2E6B5A` / `#E5EFE9` | 主行动、选中 |
| `--lpp-accent` / `--lpp-accent-ink` | `#A47F45` / `#725526` | 黄铜装饰 / 可读小字 |
| `--lpp-success` / `-warning` / `-danger` | `#2E6A4E` / `#8A5A14` / `#A03E2E` | 状态文字 |
| `--lpp-nameplate` | `#16251F` | 侧栏身份牌、深色登录左栏 |
| `--lpp-focus` / `-soft` | `#245A4C` / `rgba(36,90,76,.24)` | 焦点环 |
| `--lpp-row-hover` | `#F3F6F0` | 表格行悬停 |

- 文字对比度全部 ≥4.5:1，由 `src/styles/tokens.spec.ts` 断言（实测约 4.87–14.11:1）。黄铜只用于规则线、选中小标记与大号/装饰文字；可读小字用 `accent-ink`。
- CSS 令牌在 `src/frontend/src/styles/tokens.css`，TS 镜像在 `src/frontend/src/styles/palette.ts`；两处逐值一致，单测锁定。
- 圆角四档：标签 4 / 控件与导航 6 / 数据岛与表格 10 / 弹窗 14。阴影只给弹窗、命令面板、Toast。
- 图标为自绘 24×24 线性图标（`components/AppIcon.vue`），不依赖 Element 图标做导航。

### 字体与尺度

- 中文：`"Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", "Segoe UI", sans-serif`；不请求外部字体。
- 数字：`"Bahnschrift", "DIN Alternate", "Segoe UI", sans-serif`，表格/指标使用 `tabular-nums`。
- 等宽：`"Cascadia Mono", "SFMono-Regular", Consolas, monospace`，只给 planHash / SHA / traceId。
- 字号：12（辅助下限）/ 13（表格）/ 14（正文 1.65）/ 16（小标题）/ 20（页标题）/ 28（主标题）/ 36（指标数字）；标题行高 1.25。
- 不做全大写标签、眉标、句中点拼接、链接尾箭头；编号只给真实的八步流程。

### 间距

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56`；页面左右 28（窄屏 20/16）；表格单元 12×10；区块间距 24–30。

```
┌ 228 ┬────────────────────────────────────────────────────┐
│ 品牌 │ 工作台 / 概览     搜索 Ctrl K   用户             │ 56
│      ├────────────────────────────────────────────────────┤
│ 工作台│ 页标题 + 说明                        主操作        │
│  概览●│ ┌────────────────────────┬───────────────────────┐ │

│  任务3│ └────────────────────────┴───────────────────────┘ │
│  审查3│ 指标账本（细线分隔，非卡片）                        │
│ 数据  │ 审查队列（筛选 + 表格 + 分页）                      │
│ 设计  │                                                    │
```

- 侧栏 228px：分组“工作台 / 教案 / 数据 / 管理 / 设计”，14px 标签、18px 线性图标、右侧计数；选中态淡松绿底 + 左侧 2px 黄铜标记；底部深松绿身份牌是唯一深色块。
- 命令栏 56px，sticky；页面主操作放在页头，不放在命令栏。
- DEV 下搜索按钮打开命令面板（`Ctrl/Cmd+K`）；生产隐藏，不保留死控件。
- 断点：≥1440 完整；1100–1439 展开侧栏，<1180 主视觉上下堆叠；900–1099 侧栏抽屉、3D 仍可用；<900 结构剖面自动 2D；<1100 抽屉；<768 抽屉 280px；<640 隐藏次要元信息。
- 内容最大 1400；概览页主视觉 8/4 分栏，<1180 上下堆叠。

## 5. Element Plus 映射

只允许在 `src/frontend/src/styles/element.css` 通过变量与全局类覆盖，禁止页面级 `!important`。

| 变量 | 值 |
|---|---|
| `--el-color-primary` | `var(--lpp-primary)` |
| `--el-color-success/warning/danger` | 对应 `--lpp-success/warning/danger` |
| `--el-border-radius-base` | `var(--lpp-radius-control)` |
| `--el-font-family` / `--el-font-size-base` | 与令牌一致 |
| `--el-border-color` / `--el-fill-color-light` | `--lpp-border` / `--lpp-layer` |
| `--el-table-row-hover-bg-color` | `--lpp-row-hover` |
| `--el-table-header-bg-color` | transparent |
| `--el-dialog-border-radius` | `var(--lpp-radius-window)` |
| `--el-message-bg-color` | `--lpp-surface` |

组件默认：按钮 32/36，主按钮每屏 ≤1；输入 34；表单标签在上、12/600；表格行高 44、表头 40、透明表头底、数字右对齐；分页 12px；弹窗 14 圆角；成功/失败提示带语义色左侧竖条。成功/警告/危险按钮优先用轻色调（`plain`），不把整屏染成红绿。

## 6. 状态与文案

| 状态 | 视觉 | 文案示例 |
|---|---|---|
| loading | 自绘骨架，不闪白 | “正在加载教案…” |
| empty | 线性插画 + 原因 + 一个动作 | “还没有教案，先上传一个契约包” |
| error | code + traceId + 重试 | “读取失败（NOT_FOUND），可重试或返回列表” |
| 403 | 说明 + 返回概览 | “你没有查看该教案的权限” |
| 404 | 说明 + 返回概览 | “页面不存在或已被删除” |
| 审查状态 | 自绘 Tag：点 + 文字 + 软底 | 通过 / 放行通过 / 接受轻微 / 待修复 / 待审 / 结构失败 |
| 证据缺项 | 文字“缺项”+ 原因 | “waived 问题缺少对应放行记录：AR-2” |
| 逾期 | 文字“已逾期”+ 天数 | 不只靠红色 |

文案：主动语态、同一动作同名；“上传契约包”“登录”“重试”“清除筛选”；错误说明发生了什么、下一步怎么做。

## 7. 3D 教案结构剖面

- **目的**：把“三维目标 / 八步流程 / 证据链”作为一份教案的三层剖面展示，服务于“看结构”，不是背景装饰。
- **实现**：`three` 懒加载（`components/structure/scene.ts`）；正交相机；三层薄板（目标 / 流程 / 证据）+ 八段流程柱（高度编码分钟、颜色编码阶段）+ 五项证据方片 + 四角连接柱；无纹理、无阴影、无后处理。
- **交互**：拖拽旋转（手写指针逻辑，不引 OrbitControls）；悬停/点按三层均可命中（三维目标、流程柱、证据方块），下方说明随之更新；目标/证据的单项与汇总都有命中区；自动旋转开关；重置视角。说明与清单不依赖 3D。
- **降级**：无 WebGL、`?diagram=2d`、视口 <900、chunk 加载失败、`webglcontextlost` 时使用 `StructureDiagram.vue` 等距 SVG；窄屏隐藏 SVG 标签，由图例与结构清单承担信息。
- **性能**：DPR≤2、30fps、离屏/页面隐藏暂停、卸载时释放几何/材质/renderer/上下文；入场只跑一次 520ms，`prefers-reduced-motion` 下直接终态。
- **无障碍**：canvas `aria-hidden`，不承载唯一信息；`<details>` 结构清单包含八步、分钟、证据与缺项原因，键盘/读屏可用。
- **生产边界**：`/styleguide` 是唯一允许 fixture 的页面，只在 DEV 注册；FE-01 起真实 `/dashboard` 走接口，`three` 为懒加载生产 chunk，首屏不阻塞。

## 8. 动效

- 功能性过渡 120ms；命令面板/抽屉 140–160ms。
- 唯一的非用户触发动效：结构剖面一次性层叠入场；其余不做逐卡 fade-up。
- `prefers-reduced-motion` 下关闭自动旋转、入场、图表动画与全局过渡（保留拖拽）。

## 9. 响应式与无障碍

- 1440：完整侧栏 + 8/4 主视觉 + 表格全列。
- 1280：侧栏仍展开；主视觉与表格保持，表格列不横向溢出。
- 390：侧栏抽屉；页头纵向；结构剖面用 2D；表格容器内横向滚动并给出提示；按钮不重叠。
- 正文/次文字对比度 ≥4.5:1（单测）；焦点环 2px 实色松绿；图标按钮 `aria-label`；状态不只靠颜色；3D 信息在清单中可得；`lang=zh-CN`；跳过导航链接。

## 10. 验收方式

1. 启动前端：`cd src/frontend && npm run dev`（本机 `http://127.0.0.1:5174`）。
2. 打开 `/dashboard`（FE-01 起真实概览，需登录）、`/styleguide`（设计验收，允许 fixture）、`/login`（登录）。
3. 看 1440/1280/390 三档；3D 结构在 `/dashboard` 用真实教案内容，在 `/styleguide` 用固定演示数据。
4. 按 `component-acceptance.md` 逐项检查；反馈写入 `review-notes.md`。
5. 命令：`npm run typecheck`、`npm run lint`、`npm run test`、`npm run build`、`npm run screenshots`；仓库根 `py -3 scripts/run_backend_gate.py`。

截图目录：`.qa/frontend-review/v1.1/`（`{styleguide,login}-{1440,1280,390}.png`）；真实 dashboard 截图在 `.qa/frontend-review/fe-01/`。

## 12. 已知边界

- 真实系统页面只走接口；固定演示数据只保留在 `/styleguide`，不进真实系统导航与生产。
- FE-01 起真实 dashboard 使用 three.js，生产构建会出现懒加载 three chunk；首屏不阻塞。
- 业务页面按 FE-02…FE-09 任务推进；队列/指标/待办以真实接口为准，空数据不伪造。
- 移动端表格保留横向滚动，不做卡片化（联调任务再评估）。
- 本轮不做暗色主题、国际化、外部字体。
