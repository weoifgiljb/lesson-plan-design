# 平台端 UI 风格说明（v0.9 待验收）

> 状态：**B 配色已选（2026-10-28），布局已按 Fluent / Finder / GNOME Settings 重做，待用户确认后冻结**。确认后把结论写进文末“冻结决定 v1.0”，才允许开始业务页面任务。

## 1. 产品与受众

- 用户：中职信息技术教师（日常建课/送审）、教研组长（看本组）、管理员（用户/审计/引擎版本）。
- 核心任务：收（契约包入库）、看（教案库/版本）、审（证据链）、导（DOCX）、统（9 项指标）。
- 不是营销站，也不是低密度后台：**信息密度、状态可读、证据可追溯**优先于装饰。

## 2. 三条设计原则

1. **信息结构即视觉**：用对齐、分组、表格密度表达层级，不靠大圆角卡片堆叠。
2. **状态必须有文字**：审查状态、导出状态、逾期、证据缺项，颜色只是辅助。
3. **一屏一个重点**：每页只有一个主操作；强调色只给主操作与关键告警。

避免的默认套路：奶油底 + 高对比衬线 + 陶土色、近黑底 + 荧光绿、每个区块同款圆角卡片 + 同款阴影、全大写小标签、给每个链接加“→”。

## 2.1 操作系统参考与取舍

| 参考 | 借用 | 不照搬 |
|---|---|---|
| [Windows 11 / Fluent 2](https://fluent2.microsoft.design/) | 浅色导航 + 选中态指示条、命令栏、canvas/layer/surface 三层、4px 控件圆角、1px 描边 | Mica/亚克力材质（Web 性能与跨平台成本） |
| [macOS HIG / Finder](https://developer.apple.com/design/human-interface-guidelines/) | 侧栏 + 工具栏 + 内容优先；表格是主内容，不把每个区块装进卡片 | 红黄绿窗口按钮、系统菜单栏 |
| [GNOME HIG / Settings](https://developer.gnome.org/hig/) | 设置式“左侧章节 + 右侧分段列表”，用分隔线而不是卡片堆叠 | 顶部全局菜单、Adwaita 的固定字号 |

结论：平台端应像“桌面工作台/设置页”，而不是“后台模板”。主结构 = 浅色导航栏（选中指示条）+ 命令栏（页面动作/搜索/用户）+ 画布内容（表格/分段设置），卡片只用于确实需要边界的浮层或指标块。

共同约束：

- 语料字体：`"Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", sans-serif`；不请求外部字体；页面标题靠字重与字号建立层级，不额外引入衬线。
- 字号：12（辅助）/13（表格）/14（正文）/16（小标题）/20（页面标题）/28（概览数字）。
- 行高：正文 1.6，表格 1.45，标题 1.3。
- 间距：4/8/12/16/24/32；页面左右 24，表格单元 12×10。
- 圆角：标签 4、控件/导航 6、卡片/窗口 10；不使用全站 16+ 大圆角。
- 阴影：仅弹窗/浮层使用，`0 8px 24px rgba(20,30,40,.12)`；表格与卡片用边框，不用阴影。
- 动效：120–180ms；只用于展开、弹窗、加载；尊重 `prefers-reduced-motion`。

## 4. 布局

```
┌──────────────┬────────────────────────────────────────────┐
│ 品牌 / 角色   │ 面包屑                         用户 / 退出  │
├──────────────┼────────────────────────────────────────────┤
│ 概览          │ 页面标题                      主操作按钮   │
│ 任务          │ 筛选条（课程/周次/状态/关键字）              │
│ 教案库        │ ┌────────────────────────────────────────┐ │
│ 审查中心      │ │ 表格 / 内容区（最大 1440，左右 24）      │ │
│ 导出中心      │ └────────────────────────────────────────┘ │
│ 统计          │ 分页 / 汇总                                 │
│ 样例库        │                                            │
│ 管理（admin） │                                            │
└──────────────┴────────────────────────────────────────────┘
```

- 图标栏 76（<640 隐藏），命令栏 48，内容画布 20–24 内边距；导航用图标 + 10px 标签，不靠大段灰色占位。
- 列表页 = 筛选条 + 表格 + 分页；详情页 = 主内容 + 右侧证据/操作栏（≥1280 并排，窄屏上下）。
- 断点：≥1440 完整；1024–1439 侧栏折叠；<768 侧栏抽屉、表格转卡片。

## 6. 状态与文案

| 状态 | 视觉 | 文案示例 |
|---|---|---|
| loading | 骨架/表格 loading，不闪白 | “正在加载教案…” |
| empty | 图标 + 原因 + 一个动作 | “还没有教案，先上传一个契约包” |
| error | `code` + `traceId` + 重试 | “读取失败（NOT_FOUND），可重试或返回列表” |
| 403 | 说明 + 返回 | “你没有查看该教案的权限” |
| 404 | 说明 + 返回 | “页面不存在或已被删除” |
| 审查状态 | Tag + 文字 | 通过 / 放行通过 / 接受轻微 / 待修复 / 待审 / 结构失败 |
| 证据缺项 | 红色文字 + “缺项”标签 | “轮次不连续，缺少第 2 轮” |
| 逾期 | 文字“已逾期”+ 日期 | 不只靠红色 |

## 7. 无障碍基线

- 正文对比度 ≥4.5:1；大字号 ≥3:1；状态色不作为唯一信息。
- 键盘：Tab 顺序、焦点环 2px、Esc 关弹窗、焦点回到触发元素。
- 图标按钮必须有 `aria-label`；表单错误与字段 `aria-describedby` 关联。
- 动效尊重 `prefers-reduced-motion`；不自动播放轮播。
