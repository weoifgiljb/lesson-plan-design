# 手册格式参考（manual-v2）

本目录是平台前端教案正文的**新版视觉与内容参考**，不是业务样例库，也不参与契约校验。

## 来源与范围

- 外部参考目录：`<外部参考目录>/教材教案-手册格式/`
- 共 33 份 docx，覆盖 8 个项目、33 个任务；清单见 `manifest.json`。
- 版式：
  1. 第 1 页：课堂教学教案（院别、实习生、科目、题目、教学目的、重难点、课型、教具、参考书）。
  2. 第 2 页起：教学过程（教师活动 / 学生活动双栏，按课时连排）。
  3. 板书、板画提纲。
  4. 实习生授课情况分析（教学目的、教学执行情况、教学后记）。
- 本目录只保留一份脱敏的 Markdown 规范化样例 `项目一-任务01-C语言概述.md`，用于 Markdown 渲染与视觉 QA；不复制 33 份 docx，避免二进制膨胀和个人信息扩散。

## 脱敏约定

- 实习生、原任课教师姓名替换为 `<实习生>`、`<原任课教师>`。
- 日期、班级、院指导教师等留空字段以 `＿＿` 保留。
- 不写入学生姓名、学号或成绩。

## 视觉参考

用 LibreOffice 将 docx 转 PDF，再渲染为页面图片，放入 `.qa/reference/manual-v2/`（`.qa` 不提交）：

```powershell
soffice --headless --convert-to pdf --outdir output/tmp "<外部参考目录>/教材教案-手册格式/项目一-任务01-C语言概述.docx"
```

页面图片用于对照页眉、双栏教学过程、板书提纲与表格线；`docs/frontend/ui-style-spec.md` 的参考图指向该目录。

## 与业务契约的边界

- 平台教案正文仍由 `plan.json` 的 17 个字段生成 Markdown；本样例的手册字段不扩展后端 schema。
- 若后续要把 33 份 docx 全部转为可入库样例，需单独设计 docx 导入与字段映射，不能直接当契约包上传。
