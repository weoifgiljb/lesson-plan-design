## 板书、板画提纲

### 一、知识结构

#### 一、C 语言的产生和发展

- 计算机程序是由一系列的指令构成；创建程序时必须指定计算机要执行的指令。
- C 语言是 1972 年由美国的 Dennis Ritchie 设计发明的，首次在运行 UNIX 操作系统的 DEC PDP-11 计算机上使用。
- 1990 年，ISO 采纳 87 ANSI C 作为 ISO 的 C 语言标准（ISO 9899-1990），简称 ISO C。

#### 二、C 语言的特点

1. 语言简洁紧凑，使用灵活方便。C 语言一共有 32 个关键字，九种控制语句，程序书写格式灵活。
2. 运算符丰富。包含 34 个，运算符把括号、赋值、强制类型转换都作为运算符处理。
3. 数据类型丰富。包括整型、实型、字符型、数组类型、指针类型、结构体类型、共用体类型等。
4. 具有结构化的控制语句。代码与数据相分离，程序的各个部分除了必要的信息交流外，彼此独立。
5. 语法限制不太严格，程序设计自由度大。
6. C 语言允许直接访问物理地址，可以直接对硬件进行操作。
7. C 语言程序生成代码质量高，程序执行效率高。
8. 用 C 语言编写的程序可移植性好。

### 教学执行情况

本课共 1 课时，按“课前任务—情境导入—新授讲解—动手练习—小结作业”推进。课前学生借助任务单完成自学与检测；导入以“C 语言简单介绍，引出 C 语言是目前世界上使用最广泛的高级程序语言之一”切入，引出课题；新授围绕“C 语言的特点”展开，教师结合代码演示与任务单讲解，学生完成“小试牛刀”“任务实施”“任务拓展”等练习。

课堂小结采用师生问答、思维导图回收，作业为“课后练习”。从实施情况看，教学环节完整，重点基本落实；难点“C 语言的特点”在巡视中仍有学生卡住，主要通过个别提示、同伴互助和对照任务单解决。

### 教学后记

通过讲授和归纳总结，让同学们了解 C 语言的产生、发展过程，培养计算思维，提高解决问题的能力。
