# 契约类型化改造清单（PR #36）

> 目标：让 OpenAPI 真正表达**枚举**与**响应形状**，前端从 `types.gen.ts` 拿联合类型，不再手写 `models.ts`。
> 现状：`enum` 出现 0 次、37 个响应是 `additionalProperties: true`、`types.gen.ts` 全是 `Record<string, unknown>`。

## 1. 改造原则

1. **模型放 `app/api/schemas.py`**（协议层），domain 不 import pydantic；响应模型只描述出参，不重复业务规则。
2. **枚举用 `Literal`/`Enum` 从 domain 常量派生**，不在路由里再写字面量：
   - 任务状态 ← `task_rules.TASK_RANK` 的 keys
   - 象限 ← `task_rules.QUADRANTS`
   - 审查状态 ← `report_rules.ALLOWED_STATUS`
   - 角色 ← `roles.ROLES`
   - severity / finding 状态 ← `evidence` 里的常量
3. **先加模型、后删手写类型**：前端 `models.ts` 一次性替换为 `types.gen.ts` 的导入，避免中间态编译不过。
4. **一次只改一个端点组**，每组跑一次 `run_backend_gate.py --update-contract` + `gen_frontend_types.py` + `npm run typecheck`。

## 4. 执行顺序（每步可独立验证）

1. **工具就绪**：`sync_contract_errors --check` 并入闸门（已完成）→ 再补 BC-05 的 zh/http 比对。
2. **枚举先行**：查询参数改 `Enum`（改动小、立刻让 OpenAPI 出现 `enum`），重生成快照与类型，前端把对应 `status?: string` 改成联合类型。
3. **响应模型分批**：认证 → 任务（含看板）→ 教案 → 审查 → 统计 → 样例 → 导出/用户/审计。
   每批：加模型 → `response_model=` → 重生成 → 前端删同名手写类型 → `npm run typecheck`。
4. **错误码收口**：`errors.ts` 只保留 `code → 兜底文案`，优先用响应 `message`；补 `CATALOG ↔ ERROR_CODES` 断言。
5. **文档计数**：需求 §5.2 39→43、§5.5 14→19，`bs-dev-plan` 同步。

## 5. 风险与回滚

| 风险 | 应对 |
|---|---|
| `response_model` 与现有 dict 字段不一致 → 线上 500 | 先在测试里跑全量 `index.py`；对可选字段一律 `| None`，新增字段给默认值 |
| OpenAPI 体积暴涨、快照 diff 巨大 | 每批只提交对应改动，PR 里附 `--update-contract` 的 diff 摘要 |
| 前端 `models.ts` 删除后引用失效 | 保持 `models.ts` 作为 re-export 层（`export type TaskItem = components['schemas']['TaskItem']`），逐步迁移，不一次性删 |
| 旧快照哈希与 `types.gen.ts` 头不一致导致 BC-08 红 | 每次 `--update-contract` 后立刻 `gen_frontend_types.py`，两步同提交 |
| 查询参数变 enum 后旧前端传非法值 → 422 而不是空列表 | 前端先确认没有传自由字符串；`/reviews?status=` 的筛选值改为来自 `/meta` |

## 6. 验收标准

- `openapi.v1.json` 里 `enum` 出现次数 > 0，覆盖 `status/quadrant/role/severity/reviewStatus`；
- `additionalProperties: true` 的响应数量从 37 降到 ≤5（仅动态 detail 字段保留）；
- `types.gen.ts` 中 `Record<string, unknown>` 数量显著下降，任务/审查/统计/样例四类响应有具名类型；
- 前端 `npm run typecheck` + `check` 全绿，`run_backend_gate.py` 0 block；
- 非法 `status/quadrant/role/severity` 一律 422（有测试用例）。
