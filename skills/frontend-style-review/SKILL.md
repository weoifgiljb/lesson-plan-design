# 前端风格验收闸门

## 何时使用

- 新建或修改 `src/frontend/**` 的页面、布局、组件、全局样式；
- 用户要求“验收 UI / 组件库样式 / 看页面效果”；
- 合并前需要一份可复核的视觉与可用性报告。

不用于：纯业务逻辑、接口契约、后端代码。

## 前置证据（缺一不可）

1. 已冻结的 `docs/frontend/ui-style-spec.md`（主题、令牌、字号、间距、圆角、密度）。
2. 本页/本组件的截图：**1440、1280、390** 三档，至少覆盖默认态；表单/表格/弹窗页需补空态、加载态、错误态。
3. 主题：默认主题必须与冻结稿一致；A/B 主题切换只在 `/styleguide` 保留。
4. `component-acceptance.md` 中对应组件的勾选记录。

## 检查清单

### 1. 设计令牌

- [ ] 只通过 `styles/tokens.css` 与 `styles/element.css` 覆盖，无页面级 `!important`、无散落硬编码色值。
- [ ] 主色/强调色/成功/警告/错误/文字/边框/背景与冻结稿一致；强调色只用于关键动作。
- [ ] 字号、行高、间距落在 8px 体系；中文标点、数字与中英文混排正常。
- [ ] 圆角、阴影、边框层级一致；表格/卡片/弹窗不出现“同一圆角用到底”。
- [ ] 无外部字体请求；离线打开不缺字。

### 2. Element Plus 组件

- [ ] Button：默认/悬停/按下/禁用/加载/危险动作；主按钮每屏不超过一个。
- [ ] Input/Select/DatePicker：标签、占位、清除、禁用、校验错误、帮助文案。
- [ ] Form：必填标识、错误定位、提交中禁用、成功后反馈。
- [ ] Table：表头、斑马纹（如启用）、行高密度、超长截断、排序/筛选、分页、空态、加载骨架。
- [ ] Dialog/Drawer：标题、关闭、遮罩、Esc、焦点回到触发元素、危险操作二次确认。
- [ ] Tag/Badge：六种审查状态与导出状态颜色可区分，且不只靠颜色表达。
- [ ] Upload：类型/大小提示、进度、失败重试、成功文件名。
- [ ] Message/Notification：成功/失败文案明确，不遮挡关键操作。
- [ ] Empty/Result：说明原因并给下一步动作，不出现空白页。

### 3. 页面四态

- [ ] loading：骨架或占位，不闪空白、不跳动。
- [ ] empty：说明“为什么空”+ 一个可执行动作。
- [ ] error：展示 `code` 与 `traceId`，提供重试；不泄露堆栈。
- [ ] 403/404：说明原因与返回路径；不显示半截数据。

### 4. 响应式

- [ ] 1440：主布局完整，表格不横向溢出。
- [ ] 1280：侧栏可折叠，主要操作仍可达。
- [ ] 390：导航收起，表格转卡片或横向滚动有提示，按钮不重叠。

### 5. 无障碍与交互

- [ ] 文字对比度 ≥ 4.5:1；状态色不作为唯一信息。
- [ ] 键盘可达：Tab 顺序合理，焦点环可见，Esc 可关弹窗。
- [ ] 图片/图标有替代文本或 `aria-hidden`。
- [ ] 动效尊重 `prefers-reduced-motion`。
- [ ] 表单错误与字段通过 `aria-describedby` 关联。

### 6. 业务展示组件

- [ ] 证据链五项：通过/缺项同时有文字与颜色，缺项可展开原因。
- [ ] 版本差异：字段路径、前后值可读，长文本可折叠。
- [ ] 统计指标：分子/分母同屏，空数据显示“暂无数据”而不是 0。
- [ ] 导出队列：逐项状态、失败原因、下载入口。
- [ ] 任务：逾期有文字标记，不只靠红色。

## 判定

- **通过**：清单全部勾选，截图齐全，无未关闭的视觉 blocker。
- **有条件通过**：仅 minor（文案、间距微调、非关键状态），列出整改项与复查方式。
- **拒绝**：存在令牌失控、组件状态缺失、四态缺失、响应式断裂、无障碍 blocker。

报告落盘 `.qa/reviews/frontend-<页面或分支>-<日期>.md`，包含：截图路径、清单结果、发现（`文件:行` + 证据 + 严重度）、结论、复查记录。

## 与其它技能的关系

- 设计方向用 `frontend-design`；可访问性细审用 `web-design-guidelines`；本技能负责“是否允许合并/交付”的最终闸门。
- 与 `backend-review-gate` 互不替代：前者管视觉与可用性，后者管接口、权限、数据。
