# 校标教案硬约束（常驻）

本仓库/插件启用后，凡涉及撰写、修订、校验、导出职教教案，必须遵守下列规则。完整流程见技能 `lesson-plan-design`（`SKILL.md`），此处只放**每轮都生效**的硬约束。

1. **结构优先**：输出必须是校标字段（元信息、三维目标、八步流程），禁止只用长散文冒充教案。
2. **缺关键输入先问**：周次、课次、教学内容标题未知时，先问再生成。
3. **导出前必校验**：调用本插件 `scripts/validate.py`（或技能内同名脚本），并持有与当前教案哈希匹配的对抗审查报告。未关闭的 `blocker`/`major` 必须修复、复审或由教师实名放行。
4. **对照金标准**：草稿时按需读取 `skills/lesson-plan-design/examples/`，不要凭空编造与样例冲突的结构。
5. **默认校标**：东莞经贸学校 / 信息技术 / 计算机教研组；教学资源默认机房。
