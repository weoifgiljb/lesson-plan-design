# 校标教案硬约束（常驻）

本文件与 `AGENTS.md` 同义，供飞书妙搭 / Qoder 等以 `RULES.md` 为入口的宿主加载。

1. **结构优先**：输出必须是校标字段（元信息、三维目标、八步流程），禁止只用长散文冒充教案。
2. **缺关键输入先问**：周次、课次、教学内容标题未知时，先问再生成。
3. **导出前必校验**：运行本技能 `scripts/validate.py`，并持有与当前教案哈希匹配的对抗审查报告。未关闭的 `blocker`/`major` 必须修复、复审或由教师实名放行；`minor` 须由教师实名接受后才能导出；飞书没有 hooks 运行时同样不得跳过。
4. **对照金标准**：按需读取 `examples/`，不要凭空编造与样例冲突的结构。
5. **默认校标**：东莞经贸学校 / 信息技术 / 计算机教研组；教学资源默认机房。
