# 校标教案硬约束（常驻）

本文件与 `AGENTS.md` 同义，供飞书妙搭 / Qoder 等以 `RULES.md` 为入口的宿主加载。

1. **结构优先**：输出必须是校标字段（元信息、三维目标、八步流程），禁止只用长散文冒充教案。
2. **缺关键输入先问**：周次、课次、教学内容标题未知时，先问再生成。
3. **导出前必校验**：运行本技能 `scripts/validate.py`，并持有与当前教案哈希匹配的对抗审查报告。未关闭的 `blocker`/`major` 必须修复、复审或由教师实名放行；飞书没有 hooks 运行时同样不得跳过。
4. **对照金标准**：按需读取 `examples/`，只对照字段与八步结构，不要凭空编造与样例冲突的结构。三维目标与重难点的写法以本规则和 `schema.md` 为准，禁止照抄样例里的清单式目标。
5. **默认校标**：东莞经贸学校 / 信息技术 / 计算机教研组；教学资源默认机房。
6. **三维目标可评可测**：知识目标写学生会什么，能力目标写学生能干什么，素质目标写达成什么素养；禁止只列课题/考点清单。每条目标须能被本课活动与考核观察或检测。
7. **重难点分源**：`keyPoints` 须分写重点与难点。重点由本课教学内容确定，难点由学情确定；禁止把课题复述成一条混写。
