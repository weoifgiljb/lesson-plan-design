# 技能级规则

与插件根目录 `RULES.md` / `AGENTS.md` 一致。仅拖入本技能文件夹（飞书工作空间 `skills/`）时以本文件为准。

1. 输出必须是校标 JSON 结构，禁止只用长散文冒充教案。
2. 缺周次、课次、教学内容标题时先问再生成。
3. 导出前必须运行 `scripts/validate.py`，并持有与当前教案哈希匹配的对抗审查报告。未关闭的 `blocker`/`major` 必须修复、复审或由教师实名放行；`minor` 须由教师实名接受后才能导出；即使宿主没有 hooks 也不得跳过。
4. 按需读取 `examples/`，不要编造与金标准冲突的结构。
5. 默认：东莞经贸学校 / 信息技术 / 计算机教研组 / 机房。
